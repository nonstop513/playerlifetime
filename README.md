# 玩家生命週期預測模型

基於機器學習的玩家行為預測與分析系統

## 📊 專案簡介

本專案使用隨機森林、XGBoost 和 Logistic Regression 等機器學習演算法，預測玩家的剩餘遊玩轉數，並提供互動式視覺化儀表板進行分析。

## 🎯 模型類型

### 1. 五分類模型 (lifetime.py)
將玩家剩餘轉數分為 5 個類別：
- **類別 0**: 0~100 轉（即將流失）
- **類別 1**: 101~500 轉
- **類別 2**: 501~1000 轉
- **類別 3**: 1001~5000 轉
- **類別 4**: 5001+ 轉

**模型準確率**：
- XGBoost: 62.37%（最佳）
- 隨機森林: 52.73%
- Ordinal Logistic: 48.13%

### 2. 二分類模型 (lifetime_bin.py)
將玩家分為流失/留存兩類：
- **類別 0**: 流失（剩餘轉數 ≤100）
- **類別 1**: 留存（剩餘轉數 >100）

**模型準確率**：
- XGBoost: 76.31%（最佳）
- Logistic Regression: 73.21%
- 隨機森林: 73.21%

## 🚀 使用方法

### 1. 訓練模型並生成數據

```bash
# 訓練五分類模型並生成數據
python lifetime.py

# 訓練二分類模型並生成數據
python lifetime_bin.py
```

### 2. 查看儀表板

直接在瀏覽器中打開 `index.html` 即可查看互動式分析儀表板。

## 📈 儀表板功能

- **模型性能對比**：比較不同模型的準確率
- **混淆矩陣分析**：詳細的預測結果分布
- **時間序列趨勢**：每日流失率/類別 0 比例變化
- **隔日留存分析**：預測與實際行為的對比

## 🔍 主要特徵

- 已游玩總轉數 (played_spin)
- 已游玩天數 (played_days)
- 過去平均投注額、贏分、淨利等 17 個歷史平均特徵
- 排除數據洩漏變量（剩餘轉數、總轉數）

## 📊 關鍵發現

1. **XGBoost 表現最佳**：在五分類和二分類任務中均優於其他模型
2. **二分類準確率更高**：73%+ vs 60%+，證明流失預測比細分類別更可行
3. **最新玩家預測準確**：對最近 3 天有遊玩記錄的玩家，預測準確率達 91%+
4. **預測與實際流失相關**：Pearson 相關係數 -0.42（p<0.0001）

## 📝 資料說明

- **訓練/驗證集拆分**：按玩家 ID 的 80/20 分割

- **日期範圍**：2026/01/08 - 2026/03/18（70 天）
